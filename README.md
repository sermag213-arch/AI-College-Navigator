# AI College Navigator

AI College Navigator is an AI-powered college planning assistant
designed to help high school students make smarter college decisions.

## Problem

College planning can be overwhelming for high school students.
Students have to research majors, colleges, GPA requirements,
test scores, deadlines, applications, and financial information
across many different websites.

## Solution

AI College Navigator combines a student profile, college matching
system, planning tools, and an AI assistant into one platform.

Students enter information such as their GPA, test scores,
graduation year, and intended major. The system uses that profile
to recommend colleges that are a strong academic and program fit.

## Features

- Student profile
- Nationwide college matching
- GPA and test-score matching
- Intended-major matching
- AI college-planning assistant
- Personalized college plan
- Progress tracker
- AI explanations and recommendations

## Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask
- Featherless AI
- OpenAI-compatible API
- LocalStorage

## AI

The project uses Featherless AI with the
openai/gpt-oss-20b model.

The AI assistant uses information from the student's profile
to provide personalized college-planning guidance.

## Target Users

High school students who need help researching colleges,
choosing schools, understanding the application process,
and creating a personalized college plan.

## How to Run

1. Clone the repository.
2. Install the Python dependencies.
3. Add a Featherless API key to a local `.env` file.
4. Start the Flask backend.
5. Open the frontend.
